# 🚀 Admin Panel

A modern Admin Panel built with the MERN Stack. This project provides an easy-to-use dashboard for managing employees, departments, designations, and attendance with secure authentication.

---

## ✨ Features

- 🔐 User Authentication (Login)
- 📊 Dashboard Overview
- 👨‍💼 Employee Management
- 🏢 Department Management
- 💼 Designation Management
- 📅 Attendance Management
- 👤 User Profile
- 📱 Responsive Design
- 🔍 Search & Filter
- ⚡ Fast and User-Friendly Interface

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Bootstrap / CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kush424/ADMIN-PANEL-.git
```

### Move into Project

```bash
cd ADMIN-PANEL-
```

### Install Dependencies

Backend

```bash
npm install
```

Frontend

```bash
cd client
npm install
```

---

## ▶️ Run Project

### Backend

```bash
npm start
```

or

```bash
npm run dev
```

### Frontend

```bash
cd client
npm start
```

---

## 🌐 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGO_URI=Your_MongoDB_Connection_String

JWT_SECRET=Your_JWT_Secret
```
